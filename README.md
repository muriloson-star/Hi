# Verdura — Herbal Wellness Shopify Theme

A calm, natural, **high-converting** Shopify theme built for botanical / aromatherapy
brands — inspired by products like the EnerZen Herbal Diffuser. Earthy sage-and-clay
palette, soft serif headings, generous whitespace, and a conversion-focused homepage.

## ✨ Highlights

- **Fully customizable** through the Shopify Theme Editor — colors, fonts, spacing,
  corner radius, and all section content are editable with no code.
- **Conversion-first homepage**: hero with social proof → trust bar → benefits →
  product buy-box → how-it-works → brand story → comparison table → reviews →
  featured collection → money-back guarantee → FAQ → newsletter.
- **AJAX slide-out cart** with a free-shipping progress bar.
- **Product page** with sticky add-to-cart, variant picker, feature list,
  collapsible rows, dynamic checkout, and trust/FAQ/guarantee sections.
- Two built-in color presets: *Forest Calm* and *Warm Clay*.
- Mobile-first, accessible, and fast (no jQuery — vanilla JS).

             gift_card, password, customers/*

## 🚀 How to install

1. In Shopify admin go to **Online Store → Themes**.
2. Click **Add theme → Upload zip file** and select this `.zip`.
3. Click **Customize** to open the theme editor.
4. Set your logo (Header section), pick the product for the homepage
   **Product spotlight**, and choose a collection for **Featured collection**.
5. Adjust colors & fonts under **Theme settings**, then **Publish**.

## 🎨 Customization tips

- **Theme settings → Colors**: swap the whole palette in seconds (or load a preset).
- **Theme settings → Typography**: change heading/body fonts and sizing.
- Every homepage section can be reordered, hidden, duplicated, or edited.
- The **Product spotlight** and **Featured collection** need a product/collection
  selected to show live store data (placeholders show until then).
